
## Обновление: нагрузочное тестирование и очистка задач

В административной панели добавлена вкладка **«Нагрузочное тестирование»**. Она создаёт обычное задание на базе существующих сценариев, но помечает его как load test. При выполнении агент дополнительно отправляет в онлайн-лог строки уровня `metric`:

- Windows: CPU, RAM, количество процессов, свободное место на диске C:;
- Linux: load average, RAM, количество процессов, свободное место в `/tmp`.

Для администратора также добавлено удаление отдельных задач и массовое удаление завершённых старых задач со статусами `completed`, `failed`, `expired`, `cancelled`.

## Графики нагрузочного тестирования

В режиме **Нагрузочное тестирование** агенты отправляют строки уровня `metric` в формате `METRIC ...`. На странице задания и в HTML-отчёте автоматически строятся графики:

- Windows: CPU %, RAM %, количество процессов, свободное место на диске C.
- Linux: load average 1m, RAM %, количество процессов, свободное место в `/tmp`.

Графики строятся без дополнительных серверных зависимостей и обновляются на странице задания в реальном времени при поступлении новых `METRIC`-строк через WebSocket.

Для сохранения графиков в дипломный отчёт откройте страницу задания или отчёт, дождитесь завершения теста и сделайте скриншот блока **Графики нагрузки** либо используйте печать страницы в PDF.
